🚀 RECOMMENDED DEPLOYMENT PATH
═════════════════════════════════════════════════════════════════════════════

Platform: RAILWAY.APP ⭐ (Easiest)

Step 1: Create MongoDB Atlas (5 min)
  • Visit: mongodb.com/cloud/atlas
  • Create free cluster
  • Get connection string
  • Save it ✅

Step 2: Create Railway Account (2 min)
  • Visit: railway.app
  • Sign up with GitHub
  • Authorize Railway

Step 3: Create Railway Project (1 min)
  • "New Project"
  • "Deploy from GitHub"
  • Select zenrix-backend repo

Step 4: Add Environment Variables (1 min)
  • MONGODB_URI = [from MongoDB Atlas]
  • JWT_SECRET = [generate random 32+ chars]
  • SESSION_SECRET = [generate random 32+ chars]
  • ADMIN_PASSWORD = [your secure password]
  • NODE_ENV = production
  • HF_API_KEY = [from your .env]

Step 5: Deploy (2 min)
  • Click "Deploy" button
  • Wait for build to finish
  • Get your URL: https://your-project.railway.app
  • DONE! ✅

⏱️  Total Time: ~15 minutes
🎉 Result: Fully live website accessible worldwide

💡 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Common Issues:

  "Cannot connect to database"
  → Check MONGODB_URI is correct
  → Ensure IP is whitelisted in MongoDB Atlas

  "Admin login fails"
  → Verify ADMIN_PASSWORD matches what you set
  → Username is always: admin

  "Chatbot not responding"
  → Check HF_API_KEY is set
  → Verify it's the same as local .env

  "White blank page"
  → Hard refresh: Ctrl+Shift+R
  → Check console (F12) for errors
  → Check Railway logs for server errors

  For more help: See "Troubleshooting" section in DEPLOYMENT.md
